# เว็บแอปพลิเคชันประกวดและโหวตกระทงออนไลน์ 3D (Loy Krathong 3D Festival & Online Voting)

เว็บแอปพลิเคชันจำลองบรรยากาศงานเทศกาลลอยกระทงในรูปแบบ 3D แบบเรียลไทม์ ด้วย Three.js + React + Vite + Tailwind CSS รองรับการใช้งานทั้งบน PC, Tablet และ Smartphone

---

## 🌟 ฟีเจอร์หลัก (Features)

1. **ฉาก 3D บรรยากาศงานลอยกระทง (Three.js Scene):**
   - **แม่น้ำ (River):** ระลอกคลื่นน้ำกระเพื่อมแบบไดนามิก สะท้อนแสงจันทร์ยามค่ำคืน
   - **ดวงจันทร์วันเพ็ญ (Full Moon):** พระจันทร์สีนวลพร้อมแสงเรืองรอง (Halo glow) และโคมลอย (Floating Lanterns) ลอยสู่ท้องฟ้า
   - **สถาปัตยกรรมไทย (Thai Heritage):**
     - พระอุโบสถ / วัดทรงไทย หลังคาซ้อนชั้น ช่อฟ้า และไฟส่องสว่าง
     - พระเจดีย์สีทองอร่าม พร้อมสปอตไลต์ส่องประกาย
     - หมู่เรือนไทยยกใต้ถุนสูงริมฝั่งแม่น้ำ
   - **ผู้คนเดินชมงาน 20 คน:** ตัวละคร 3D เดินไปมาตามทางเดินริมน้ำอย่างมีชีวิตชีวา
   - **กระทงหลากสี 20 กระทงเริ่มต้น:** ลอยกระเพื่อมตามระลอกคลื่น พร้อมแสงเทียนและธูปเรืองแสง

2. **การควบคุมมุมกล้อง 360 องศา (OrbitControls):**
   - หมุนฉาก (Rotate), ซูมเข้า (Zoom in), ซูมออก (Zoom out) ได้อย่างราบรื่น
   - มีระบบป้องกันการหลุดมุมมองลงใต้พื้นน้ำ

3. **ระบบถ่ายภาพและส่งกระทงเข้าประกวด (Selfie & Creation Flow):**
   - ถ่ายภาพสดผ่านกล้องหน้า (Webcam/Mobile Camera) หรืออัปโหลดรูปภาพ
   - ป้อนชื่อผู้ประกวด และคำอธิษฐาน
   - เลือกรูปแบบกระทง (กระทงใบตองวิจิตร, กลีบบัวสวรรค์, กล้วยไม้ทิพย์, สุวรรณหงส์)
   - เมื่อกดบันทึก กระทงใบใหม่จะถูกปล่อยลงสู่แม่น้ำ 3D ทันที

4. **การแตะกระทงและโหวตคะแนน (Interactive Voting):**
   - แตะหรือคลิกกระทงใบใดก็ได้ในแม่น้ำ
   - ป๊อปอัปจะแสดงภาพถ่าย, ชื่อเจ้าของ, คำอธิษฐาน และคะแนนโหวต
   - กดปุ่ม **"โหวตกระทงใบนี้"** พร้อมเอฟเฟกต์พลุกระดาษฉลอง (Confetti) และนับคะแนนทันที

5. **กระดานจัดอันดับ (Leaderboard):**
   - แสดงรายชื่อและคะแนนโหวตของผู้เข้าประกวดทั้งหมด เรียงตามความนิยม
   - สามารถคลิกที่ชื่อในตารางเพื่อเปิดดูข้อมูลและกระทงได้ทันที

6. **เสียงดนตรีไทยบรรยากาศ (Ambient Thai Chimes):**
   - ระบบจำลองเสียงระนาดและกังสดาลไทยด้วย Web Audio API แบบเปิด-ปิดเสียงได้

---

## ☁️ การเชื่อมต่อ Firebase Firestore & การบีบอัดรูปภาพ

- **Real-time Database:** บันทึกข้อมูลกระทงและคะแนนโหวตลงในคอลเลกชัน `krathongs` ของ Google Cloud Firestore
- **Real-time Synchronization:** ใช้ `onSnapshot` เพื่อซิงก์กระทงใหม่และผลโหวตให้ผู้ใช้ทุกคนเห็นพร้อมกันสดๆ ทันที
- **Smart Image Compression:** ฟังก์ชันบีบอัดรูปภาพอัตโนมัติ `compressImageToMax500KB()` ปรับขนาดภาพและลดคุณภาพแบบวนซ้ำจนได้ขนาดภาพ **ไม่เกิน 500 KB** อย่างแม่นยำ ปลอดภัยตามขีดจำกัดของ Firestore document

## 🚀 วิธีการรันโปรเจกต์ (Development & Build)

```bash
# 1. ติดตั้ง Dependencies
npm.cmd install

# 2. เริ่มรันเซิร์ฟเวอร์ทดสอบ (Development Server)
npm.cmd run dev

# 3. ตรวจสอบและ Build สำหรับ Production
npm.cmd run build
```

เปิด Browser ไปที่: [http://localhost:3000](http://localhost:3000)
